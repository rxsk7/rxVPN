Что не работает?

          

            
            
            
            
          

        


        

          
Через zapret, мимо VPN

          

            
            
            
            
            
            
          

          
Быстрее и без расхода трафика VPN: «замедлялку» провайдера обходит zapret прямо у тебя, а остальное
            идёт через VPN как обычно. Отмеченные сайты при этом видят твой настоящий IP. Нужны права администратора.
            Добавил сервис — нажми «Подобрать лучшую» в «Стратегии zapret»: стратегия проверится и на нём.

        


        

          
DNS без подмены · «Без VPN»

          

            
            
          

          
В режиме «Без VPN» Windows спрашивает адреса сайтов у rxvpn, а rxvpn — у Cloudflare, Google или
            твоего сервера по HTTPS: провайдер не подсунет заглушку вместо сайта и не увидит, что ты открываешь по DNS.
            На время работы rxvpn ставит в сетевые карты DNS 127.0.0.1, прежние остаются запасными; отключил или закрыл
            rxvpn — всё как было. Нужны права администратора (как и zapret).

        


        

          
Telegram · без VPN

          

            
            
            
          

          
Telegram Desktop ходит к своим серверам через веб-вход, как web.telegram.org: его режут
            слабее. VPN не нужен, переписка шифруется как обычно. Включи → «Подключить Telegram Desktop» → в Telegram
            «Подключить прокси». Мобильный Telegram и звонки так не работают.

        


        

          
Анонимность и выход

          

            
            
          

          
Tor идёт через твой VPN: сайт видит выходной узел Tor. WARP — выход через Cloudflare поверх своего
            сервера, для сервисов, которые не пускают с адресов хостеров (добавляется у сервера: «⋯» → «WARP поверх»).

Настройки


      

      
Запуск

      
      
      
      
Выйти совсем — правой кнопкой по значку у часов → «Выход».

      
      
Нужно для zapret и режима «Весь комп»: они меняют сеть всего компа (драйвер WinDivert,
        сетевой адаптер TUN), а Windows разрешает это только администратору. С галочкой rxvpn при каждом
        запуске — и при входе в Windows — спросит права в окне «Да/Нет». Без неё спросит только когда
        понадобятся. Окно появилось, а rxvpn ты не запускал — жми «Нет».


      
Подключение

      

        
        
      

      
Не ставь 10808/10809 — их занимают Happ и v2rayN.

      
      
      
Упал VPN — интернет закрывается, пока не подключишься снова: ни одна программа не уйдёт в сеть
        с твоим настоящим IP. Локальная сеть (принтер, роутер) работает. Не работает вместе с «Через zapret, мимо VPN».
        Закрыл rxvpn — блокировка снимается сама.

      
      
Прокси откроется для всей сети без пароля. Включай только дома, не в кафе и не в общежитии.

      

        
        
      

      
0 часов — не обновлять самому.


      
Обход блокировок (анти-DPI)

      
      

        
        
      

      
      
Включай, если сервер не подключается или сайты «висят»: провайдер ищет имя сайта в первом
        пакете, а по кускам его не узнаёт. Работает и с REALITY. Цена — примерно +0,1–0,2 с на каждое новое
        соединение. Если провайдер режет по IP сервера, не поможет — тут нужен каскад.


      
Уведомления

      

        
        
      

      
Когда сервер перестал отвечать, «Авто» переключился, ядро упало, подключение из трея.


      
DNS

      

        
        
      

      
        
        
        
        
        
      
      
        
        
        
      
      
«Через VPN» — для заблокированного (и всего в режиме «Всё»). «Напрямую» — для .ru, адресов
        серверов и всего в «Только блок.». Можно IP, tcp://IP:порт или https://…/dns-query (DoH).

      
      
      

      
Защита

      
      
state.json (сервера, подписки) шифруется ключом твоей учётки Windows: украденный или
        случайно отправленный файл, облако, флешка, другая учётка — его не прочитают. От вируса, который уже
        работает под твоей учёткой, это не спасает. Минус: просто скопировать папку на другой комп больше
        нельзя — переноси через «Сохранить бэкап».


      
Бэкап и перенос

      

        
        
        
      

      
В бэкапе всё: сервера, подписки, правила, настройки — и пароли от серверов, никому его не
        отправляй. Для v2rayN выбери файл guiConfigs\guiNDB.db в его папке: перенесу подписки и сервера,
        добавленные вручную.

Свои сайты

      
По одному на строку: сайт (поддомены входят), ссылка целиком, IP или подсеть.
        Строки с # — комментарии. Работает в любом режиме маршрутизации.

      
      
      

        
        
      

    

  

  
  
    

      
Свои сайты мимо VPN

      
Эти сайты идут напрямую, а «замедлялку» провайдера для них обходит zapret. По одному на строку:
        site.com (поддомены входят) или ссылка целиком. IP и geosite нельзя — zapret узнаёт сайт по имени.

      
      

        
        
        
      

    

  

  
  
    

      
Tor

      
Tor встроен в rxvpn (Arti) и подключается к сети Tor через твой VPN: провайдер видит только VPN,
        VPN-сервер — что ты в Tor, сайт — выходной узел Tor. Работает только при подключённом VPN. Медленнее обычного,
        через Tor идёт только TCP (звонки, игры и QUIC — нет).

      
      
      
      

      
В «Всё через Tor» DNS-запросы программ в режиме «Весь комп» идут через VPN, не через Tor.
        Для анонимности лучше Tor Browser: браузер сам по себе выдаёт много лишнего.

      

        
        
        
      

    

  

  
  
    

      
Белые списки

      
На мобильном интернете бывает режим белых списков: открываются только госуслуги, банки, Яндекс,
        VK и т.п., остальное и обычные VPN-серверы — нет. Если VPN перестал отвечать, rxvpn проверит напрямую: открываются
        только разрешённые сайты — значит, это белые списки. Тогда он переключится на сервер ниже (его ты добываешь
        сам — обычно каскад через российский сервер на «белом» адресе) и вернётся обратно, когда режим кончится.

      
      
      

      

        
        
        
        
      

    

  

  
  
    

      
Программы

      

        
        
      

      

      
      

        Запущенные программы
        
        
      

      

      
Лучше всего работает в режиме TUN. В режиме «Прокси» действует только на программы,
        которые сами ходят через системный прокси (браузеры, Telegram, Discord). Можно указать папку — D:\Games\ — тогда правило для всех программ в ней.

      

        
        
      

    

  

  
  
    

      
Правила маршрутизации

      
Проверяются сверху вниз и раньше «Своих сайтов» и «Программ» — первое подошедшее решает.
        В одном правиле все заполненные условия должны совпасть одновременно (сайт и программа и порт).

      

        
        
      

      


      
Списки блокировок · для «Только блок.»

      

        
        
      

      
      
Источник — runetfreedom (antifilter + re:filter), обновляется каждые 6 часов. Качается ~90 МБ, на диске остаётся ~3 МБ.


      

        
        
      

    

  

  
  
    

      
Нужны права администратора

      
TUN создаёт в Windows виртуальный сетевой адаптер — без прав администратора это нельзя.
        rxvpn перезапустится, Windows спросит разрешение, и сразу подключится.

      
Чтобы не спрашивало каждый раз: правой кнопкой по rxvpn.exe → Свойства →
        Совместимость → «Запускать эту программу от имени администратора».

      

        
        
      

    

  

  
  
    

      
Zapret · без VPN

      
Обход замедления YouTube и блокировки Discord прямо у провайдера — без VPN-сервера.
        Стратегии Flowseal уже внутри rxvpn: просто нажми «Подобрать лучшую». Движок (winws и драйвер WinDivert)
        при первом запуске скачается с официального GitHub bol-van/zapret, со сверкой хеша.

Стратегии

      

        
        Готовлю…
        
      

      

      

      


      
      
Подбор включает каждую стратегию на пару секунд и открывает сайты по TLS 1.3, TLS 1.2 и HTTP —

Папка

      

      
      

      

        
        
        
        
      

    

  

  
  
    

      
Фильтры

      

        
В списке и трее останутся только эти сервера подписки — из них же выбирают «Авто» и
          «Скорость всех». Обновление подписки фильтр не сбрасывает. Пусто — показывать все.

        
        
        

        
        
      

      
Для всех серверов

      
      
      
Выбранный сервер не скрывается никогда. «Проверить все» проверяет и мёртвых — ожившие вернутся.
        Метка «мёртвый» живёт сутки; если мёртвыми оказались все (пропал интернет) — не скрывается никто.

      

        
        
        
        
      

    

  

  
  
    

      
WARP

      
rxvpn заведёт бесплатную учётку Cloudflare WARP и добавит сервер «WARP · …»: трафик идёт
        через этот сервер, а дальше — через Cloudflare. Провайдер видит только твой сервер, сайты — адрес Cloudflare.
        Удобно для сервисов, которые не пускают с адресов хостеров. Скорость — как у сервера или чуть ниже.

      
Ключ WARP хранится вместе с серверами (в бэкапе тоже). Ссылки для телефона у WARP нет.

      
      

        
        
        
      

    

  

  
  
    

      
Свой сервер

      
rxvpn сам поставит на твой VPS VPN (официальный Xray, VLESS + Reality) и закроет сервер:
        вход только по ключу, ufw, fail2ban, автообновления. Нужна чистая Ubuntu 22.04 / 24.04 или Debian 12,
        вход root и свободный порт 443. Пароль используется один раз и нигде не сохраняется.
        После установки вход по паролю выключится — останется ключ rxvpn: сразу сохрани его
        кнопкой «Сохранить ключ SSH» у сервера (переустановишь Windows — без него не войти).

      

        
        
        
        
        

          Вместо пароля — SSH-ключ
          
          
        

      

      

        
Отпечаток ключа сервера:

        
        
Сверь с сервером: в веб-консоли хостера выполни
          ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub — первая часть строки должна совпасть.
          Не совпадает — не продолжай: между тобой и сервером кто-то есть. Дальше rxvpn сверяет этот отпечаток сам.

Почему не открывается сайт

      
Проверю, что с ним сделал провайдер: подменил адрес, заблокировал по IP, режет по имени
        или замедляет, — и скажу, что включить.

      

        
        
      

      
    
      
    
        
    
        
    
        
    
          
          
          
        
    
      
    
      
    
        
      
    
    
    
      

  
  
    
    
      
    Сервисы
    
      
    
      
      
      
      Обычные запросы, как из браузера, без входа в аккаунты. Сервисы иногда меняют свои страницы —
        тогда будет «не понять»: это значит, что проверить не вышло, а не что не работает.

      Профили по сети
      
      
      
      Смотрю, где ты…
      
      
      
      
      
      
      В своих сетях
      
      
      
        
        
      
      
      
      В остальных сетях (кафе, работа, кабель, телефон)
      
      
      
        
        
      
      
      
      Срабатывает, когда сеть меняется; что переключишь руками — держится до следующей смены.
        Своя сеть узнаётся по имени Wi-Fi и адресу точки доступа: поддельная точка с таким же именем
        считается чужой. Несколько точек дома (mesh) — нажми «Это моя сеть» у каждой.
        Windows 11 отдаёт имя Wi-Fi, только если включено «Параметры → Конфиденциальность → Расположение →
        Разрешить классическим приложениям доступ к расположению».
      
      
      
        
        
      
      
    
      
        

  
  
    
      
      
      Обход
      
      
      Пробую варианты разом: без обхода, нарезку первого пакета, другой отпечаток браузера.
        Первый рабочий (самый незаметный) запомню для этого сервера. Подключение не трогаю.
      
      
        
      
        
      
        
        
        
        
      
        
    
        
          

  
  
    
        
      
        Сайт → свой сервер
        
      
        Эти сайты всегда идут через выбранный сервер, остальное — как обычно. Например, ChatGPT — через
        американский, YouTube — через голландский. Действует в любом режиме и главнее «Своих сайтов».
        Подойдёт ли сервер — кнопка «Сервисы» у него в списке.

        IP-адрес

        Утечка DNS
        
      
        Кто видит, какие сайты ты открываешь (DNS-запросы). Около 10 секунд.

        ↓ скачивание—
        
        
        ↑ загрузка—

        Сервер DoH
        
      
        Куда rxvpn отправляет DNS-запросы по HTTPS в режиме «Без VPN». Сертификат сервера проверяется.
        
      
        
        
        
        
      
        
      
      
        Например, NextDNS или AdGuard DNS со своей ссылкой. Только https://. Адрес по имени ищется один раз
        при включении — через DNS Windows, до того как его поменяет rxvpn.
